# One figure format per story

*One figure format across a run of related slides, reusing the one students met first; no panel that shows a concept not yet taught (Ch 5 COMs widgets)*

On 2026-10-13 the professor reviewed Ch 5's three COMs slides (conservative-coms modes "first", "dial" and "optimiser").
- First complaint: they could not read a right panel plotting "true value along the search" against search step. Algorithm 2 had not been taught yet on that slide.
- That panel was replaced, by me and by the "Lecture 5 준비" session, with three different right panels: a magnified D, a promised/real bar card, and a three-group bar card. The professor's verdict: "그림 형식이 다 다르다. 이해가 잘 안된다. 최대한 직관적으로 심플하게."
- Final fix: all three modes now draw ONE figure, Act 1's "Where the loss comes from" chart (surrogate-exploit mode "bound"). It is one design-axis chart with a readout column. A choice x̂ is a dot on the surrogate plus a ring on the truth, B is the line between them, A is amber at x*. μ sits on the floor, a key sits top-left, and there is no second panel.

**Why:** each new figure type costs the audience a re-read. A derived axis (steps) or a separate bar panel splits attention from the picture they already know how to read.

**How to apply:**
- When several slides tell one story, give them the same figure and change one thing per slide.
- Reuse the format introduced earliest in the lecture.
- Prefer a key over inline curve labels when curves move (sliders), so labels never collide.
- Every panel must use only concepts already introduced.
- When the professor needs an explanation to follow a slide, build it into the slide as a picture plus one line.
