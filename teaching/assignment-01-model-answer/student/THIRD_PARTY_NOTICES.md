# Third-party notices

The Movie-First audience app in this package bundles the libraries listed below. The public landing, Markdown reading views and Response Model Simulator also embed three font families; their full official upstream licenses appear after the library notices. Notices are reproduced from the installed distributions used by the build, with a clearly marked upstream snapshot where a distribution omitted its license file. Original copyright holders and license wording are preserved. This attribution does not identify the organizations or people in the synthetic cinema case.

Library notices apply to [the Movie-First audience app](audience/demo.html), including its embedded Worker. The [Response Model Simulator](response/demo.html) embeds its original calculation code without third-party JavaScript libraries. Libraries are selected from esbuild's actual output contributions; build-only tools are excluded.

Regenerate from the source repository with `node teaching/ie437-model-answer/build-apps.mjs`. References below use package-relative filenames; no local installation paths are included. Font snapshots are stored in `teaching/ie437-model-answer/vendor/font-notices.md` for offline regeneration.
